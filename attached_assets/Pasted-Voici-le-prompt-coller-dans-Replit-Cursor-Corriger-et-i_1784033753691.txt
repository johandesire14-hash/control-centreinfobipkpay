Liste des garages → depuis table garages
Notes et avis → depuis table reviews
Statistiques → calculées depuis Supabase

Vérifiant que la colonne specialties existe dans la table garages

Synchronisant avec ce que le pro a sélectionné dans son dashboard

Le badge rouge sur la cloche disparaît

Ajouter colonne is_read BOOLEAN DEFAULT false dans la table notifications si elle n’existe pas

Dans ‘Mes favoris’, bouton ‘Retirer’ doit supprimer de Supabase et retirer de la liste immédiatement
Synchroniser partout : page publique + liste des favoris

Je veux créer un nouveau compte
Autre raison (champ texte libre)

Le compte Supabase Auth (supabase.auth.admin.deleteUser)

Les conversations et messages
Les favoris
Le garage si c’est un pro

Les avis laissés sur les garages (anonymisés avec ‘Utilisateur supprimé’)
